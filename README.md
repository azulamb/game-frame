# game-frame

## Samples

- [Basic sample](docs/index.html)
- [Wire dungeon](docs/dungeon.html): 16×16 random dungeon drawn with Canvas 2D lines.
  Select dungeon entry or key configuration on the title screen.
  The D-pad moves forward/backward and strafes left/right; L/R turn 90 degrees.
  Cancel returns to the title. Each entry generates a new connected dungeon.

## Build

```sh
tsc -p src
```
